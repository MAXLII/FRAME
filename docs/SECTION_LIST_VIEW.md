# 链表顺序页面

“链表顺序”页面通过通用调试协议读取下位机当前注册的链表及节点地址，并结合 Keil MAP 文件显示实际执行顺序。

页面使用独立的目标地址、动态地址和 MAP 文件路径。点击“刷新链表列表”后，上位机只用 `0x01/0x38` 逐项读取链表目录，并在目录完整返回后一次性更新左侧列表。用户选择其中一条链表并点击“刷新所选链表”后，上位机才用 `0x01/0x39` 读取该链表的节点地址。

右侧详情区使用表格显示当前链表，列出节点顺序、对象名称和地址。读取过程中每收到一个节点就追加一行，并显示当前接收进度。

节点表支持复制单个单元格。点击目标单元格后按 `Ctrl+C`，或在目标单元格上右键选择“复制单元格”，剪贴板中只写入该格显示的文本。

上位机按链表 ID 缓存已经读取的节点。切换链表时优先显示缓存内容，点击“刷新所选链表”可重新读取该链表并替换缓存。重新刷新目录时，仍然存在的链表保留缓存，已经移除的链表同步清除缓存，新增链表以“未读取”状态加入目录。

下位机上传 `section_item_t.p_obj` 指向的注册对象地址。上位机按该地址查找 MAP 符号名称；找不到时保留十六进制值并显示为“未解析对象”。
