# SFRA

## 用途

配置并执行软件扫频，查看幅值和相位曲线，保存或打开扫频记录。

## 操作步骤

1. 连接设备后点击“获取对象”，选择扫频对象。
2. 等待读取设备配置，检查起始频率、终止频率、注入幅度和扫频点数。
3. 修改允许编辑的配置项后点击“应用配置”，再点击“状态”确认设备状态。
4. 点击“启动”执行扫频，结束后在记录列表中选择数据。
5. 点击“窗口自适应”调整幅频、相频显示范围；按需导出或打开本地数据。

## 说明

- 扫频点数由设备上报，当前界面不支持修改。
- 扫频会向被测系统注入信号，启动前请确认设备处于适合测量的状态。
- “停止”和“复位”会改变设备运行状态。
