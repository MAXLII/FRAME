# Scope 录波

## 用途

控制设备环形录波，读取触发后的采样数据，并查看或导出历史录波。

## 操作步骤

1. 连接设备后点击“获取对象”，选择要操作的录波对象。
2. 需要查看通道配置时点击“通道”；点击“状态”确认设备当前状态。
3. 点击“启动”，在合适时机点击“触发”。
4. 等待设备录波就绪，再点击“拉取录波”。
5. 在“录波记录”中切换已缓存的记录；使用“导出…”保存数据，或“打开数据…”加载本地记录。

## 说明

- “停止”和“复位”会改变设备录波状态，请先确认是否仍需拉取当前记录。
- 图表按设备采样顺序显示；鼠标滚轮缩放，拖动可平移视图。
- 录波对象和可用通道来自当前设备，不同固件可能不同。
