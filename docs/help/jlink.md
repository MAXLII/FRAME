# J-Link

## 用途

通过 J-Link 连接目标芯片，结合 ELF 或 AXF 符号查看变量；可选用 MAP 辅助定位。

## 操作步骤

1. 选择目标器件和 SWD 或 JTAG 接口，确认探针及速度设置。
2. 选择与目标固件一致的 ELF 或 AXF 文件；需要时再选择 MAP 文件。
3. 点击“Connect”连接探针，再点击“Load”加载变量。
4. 使用搜索框查找变量；展开结构体、数组或指针查看成员，点击“Refresh”更新数值。
5. 完成后点击“Disconnect”。

## 说明

- 变量名称、类型和地址来自符号文件；符号文件与目标固件不匹配时结果可能错误。
- 修改变量值会影响运行中的设备，请在确认目标与数值后执行。
- 连接失败时检查目标器件、接口、供电和探针占用状态。
