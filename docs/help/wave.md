# 参数波形

## 用途

持续采集参数值并绘制时间曲线。可以管理曲线显示、多个波形框、时间测量和数据导出。

## 操作步骤

1. 先在“参数读写”页双击参数名称，将需要的参数加入波形。
2. 在本页设置上报周期，点击“开始”采集；左侧曲线列表可控制各曲线是否显示。
3. 使用鼠标滚轮缩放、拖动平移；点击“最新数据”返回最新采样位置，点击“自适应 Y 轴”调整纵轴。
4. 点击“增加波形框”建立新框；将曲线名称拖到目标波形框可调整分组。
5. 点击“测量时间差”，依次选择两个时间位置；按 Esc 或清除按钮取消测量。
6. 使用“导出…”保存采集数据，或用“打开…”查看已有数据。

## 说明

- 鼠标移动到曲线区域时，左侧显示该时间附近的数值；离开后显示最新值。
- “暂停显示”只冻结画面，不停止设备采集和文件保存。
- “清除波形”会清除当前波形数据；需要留存时先导出。
