# 参数读写

## 用途

读取设备参数字典，查看参数值，并对允许修改的参数执行读写。参数也可从这里加入参数波形。

## 操作步骤

1. 在公共栏连接设备，从“地址”下拉框选择曾使用的地址，或在同一框内输入新的 0–255 地址并按回车。已有保存数据的地址会显示上次的参数；新地址显示空表。
2. 点击“读取参数列表”，等待列表加载完成。
3. 使用搜索框查找参数；选中参数后点击“读取”获取当前值。
4. 对可写参数修改数据，再点击“写入”。命令型参数的按钮会显示为“执行”。
5. 双击参数名称可将其加入或移出参数波形；绿色名称表示已加入。

## 说明

- 只读参数不能写入。写入时会检查类型与范围，并通过确认或回读报告结果。
- 参数读取或写入成功后自动保存到本地；切换地址和关闭软件时也会保存当前表格与未写入设备的编辑值。下拉列表只显示曾使用过的地址；重新打开软件会恢复上次地址及各地址已保存的数据。
- “读取参数列表”会重新从当前地址读取并替换该地址的旧列表。如果读取失败，屏幕可保留已收到的部分参数，旧的完整保存数据不会被自动覆盖。
- 切换设备地址后，下一次操作使用公共栏当前地址；持续采集期间不要切换目标。
