# 实时示波器

## 开始采集

1. 连接顶部公共通信链路，用于参数设置、通道同步和采集启停。
2. 在主页“数据链路”连接波形上传端口；TCP 可点击“搜索设备”。
3. 点击“选择参数”，选择当前固件的 ELF，MAP 可选。结构体右键“展开成员”，再将具体成员加入通道。
4. 添加、替换或移除通道会立即通过顶部公共链路下发配置；应答同时刷新只读采样率。调整缓存和窗口时长后点击“运行”。

最多 32 通道。每次“选择参数”都从硬盘重新读取 ELF。“参数同步”会重新定位并完整下发所有驻留通道；空列表也会清空设备配置。添加和同步只准备配置链表，运行时再切换活动链表。仅收到设备确认后才显示“已同步”，失败时保留待下发状态。

采样率不定时轮询，随通道配置应答返回。显示 `0` 表示设备尚未接入采样中断，仍可配置通道，但不能开始采样；“待同步”表示尚未获得当前连接的配置应答。旧版固件通过能力应答兼容读取采样率。

结构体可双击或右键展开；选择具体数值成员加入通道。混选时只添加可采样成员，灰色菜单悬停可查看原因。

搜索在已加载的参数及成员中筛选，忽略大小写；连续输入停止约 150 ms 后一次刷新结果。成员匹配时保留父节点，清空搜索恢复原展开状态。搜索不重复读取 ELF；点击“选择参数”仍重新读取磁盘文件。

## 波形操作

- 时间：窗口滚轮只缩放时间轴，拖动浏览波形，“实时”恢复跟随；精确时长在主页“窗口 / ms”修改。时基只改变显示范围，不缩减历史容量或清空缓存，跨越 500 ms 模式边界也保留数据。停止和冻结保留当时完整历史容量内的原始点位，可继续放大、缩小和浏览；小于一个采样间隔时仍显示相邻点之间的线段。
- 量程：直接在通道表 `/div` 输入数值或悬停滚轮调节；窗口滚轮不改变纵轴。
- 停止：停止采样；冻结：只暂停显示，后台继续接收。改变时基不会解除冻结，恢复显示需点击“继续”。
- 自动设置：利用已保留的真实点位，独立适配所有可见通道的 `/div` 和垂直位置，并按可见周期信号中的最长周期显示约三个周期。隐藏通道不参与，直流保持现有窗口，采样率和原始点位不变。

使用 base 的可调 demo 固件时，可在“参数读写”列表搜索 `DEMO_SCOPE`，写入 `DEMO_SCOPE_AMPLITUDE`（正弦峰值，默认 2）和 `DEMO_SCOPE_FREQUENCY`（波形 Hz，默认 50）。正在采集时也可修改；这是下位机生成的波形参数，不改变设备固定采样率。固件更新后重新选择对应 ELF 并“参数同步”。

## 触发

| 窗口总时长 | 可用模式 |
| --- | --- |
| ≥500 ms | 滚动，不触发 |
| <500 ms | 自动、普通；可使用单次捕获与触发冻结 |

自动模式在没有触发时也刷新；普通模式等待触发后更新；单次捕获完成后停止采样。主页选择触发源和边沿，电平与位置直接拖动游标调整，不设数字输入框。右侧带 T 的左向三角游标贴着右边框，拖动时显示电平横线，松开后隐藏横线；顶部三角标记控制触发位置。运行及滚动模式始终保留标记，滚动模式允许预调游标但不等待触发。

## 游标与测量

默认打开“通道”页，X1/X2、Y1/Y2 均不勾选。需要时切换到“测量 / 游标”页开启并拖动，侧边显示时间、幅值及差值。测量包含峰峰值、均值、RMS、频率、周期等，按所选通道读取。触发 T 标记独立于测量游标，仍保持显示。

历史容量默认 10 秒，设备采样率以查询到的 Hz 显示。波形不自动保存；超过设备带宽或缓存上限时会提示并停止采集。

曲线按绘图区像素宽度生成保留极值的显示包络，只在点位稀疏时使用保形插值，经过显示采样点且不引入过冲；触发、游标读数和测量使用原始采样，缺失数据保持断线。插值不提高真实采样精度。

通过 `run_dbg.bat` 启动时，通信日志在 `logs/communication`。`realtime_scope_device` 记录设备采样计数、队列水位、出队计数及停止原因；`realtime_scope_rx` 记录接收序号缺口、重复、拒绝帧及待处理样本。顶部公共链路的“丢弃”计数不代替示波器数据完整性统计。
