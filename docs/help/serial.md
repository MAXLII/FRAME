# 串口调试

## 用途

发送 HEX 字节或 UTF-8 文本，查看发送与接收记录，并可将接收数据保存到文件。顶部公共栏负责选择串口或 TCP 连接、波特率、设备地址和发送协议。

## 操作步骤

1. 在公共栏选择连接方式，填写端口或 IP 地址，点击“连接”。
2. 发送十六进制字节时填写“发送 HEX”；发送文字时填写“发送文本 / UTF-8”，并勾选“使用 UTF-8 文本发送”。
3. 按需勾选“追加 CRLF”和“接收显示 UTF-8 文本”，然后点击“发送并接收”。
4. 只监听设备数据时设置接收时长，点击“接收”；需要重复发送时设置大于零的重复间隔。
5. 点击“停止接收”结束持续接收；使用“导出接收数据…”保存记录。

## 说明

- “显示其他页面通信”控制参数、波形等页面产生的协议收发是否也显示在串口记录中。
- 手动向上滚动会暂停跟随最新记录；滚动回底部或重新连接会恢复跟随。
- “清空显示”只清除当前显示记录。请先导出需要保留的数据。
