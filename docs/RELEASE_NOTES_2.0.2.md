# FRAME 2.0.2

## 参数波形

- 首次收到数据时，显示最新采样附近的时间范围，避免将首批数据过滤到只剩一个点；单点显示标记，空数据刷新保持坐标轴稳定。
- 增加“最新数据”按钮，返回最新采样位置并继续跟随，保留当前缩放范围。
- 双击参数开启上报并加入曲线列表，默认不显示到波形框；拖入波形框或手动选择后显示。
- 移除“窗口 s”、窗口预设选择和“全图”按钮，整理剩余工具栏控件。

## 后端与诊断

- 后端服务、命令、协议、主动上报和采集策略采用模块注册机制，保留现有 C ABI 和 FRAME 协议。
- CLI/Shell 增加 `backend catalog`，支持查询实际注册项。
- `run_dbg.bat` 自动启用通信日志，写入仓库 `logs/communication`；记录命令、ACK、超时、取消及每秒通信状态，每个会话最多保留两个约 8 MiB 的轮转文件。
- 诊断日志用于定位通信停止响应；本版本不宣称已经修复尚未定位的现场通信停滞问题。

## 安装包

Windows x64 独立运行安装包，包含 .NET 运行时和原生后端。Release 同时提供 SHA-256 校验文件和构建清单。

发布验证包含原生注册／协议／流式链路／运行时回归、CLI/Shell 冒烟、波形界面回归，以及安装包解包、文件哈希、CLI 和 WPF 启动检查。回放与本地测试不替代 PLECS 现场故障复现。
