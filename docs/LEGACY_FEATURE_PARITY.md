# 旧 FRAME 实用功能迁移对照

参考 Git 基线 `daf3d2c` 的 `ui/parameter_tab.py`、`ui/wave_tab.py`、`ui/monitor_tab.py`、`ui/app.py` 和 `ui/settings_persistence.py`。这些文件仅通过 Git 查看，不恢复到产品源码。新功能继续复用 C++ 后端与 Frame.Client。

## 本轮实现

| 功能 | 新版行为 |
|---|---|
| 设置记忆 | 正常退出保存 COM、波特率、地址、TCP 地址/端口、连接类型、窗口大小、侧边栏状态及常用页面字段；启动恢复，不自动连接或执行设备操作 |
| 参数到波形 | 双击参数名称切换加入/移出，ACK 成功后变绿并同步波形已选列表；不显示开启/关闭上报按钮；停留参数页便于连续选择，命令参数不能作为波形；取消后历史记录不会重新加入该参数 |
| 参数列表实时刷新 | 后端通过现有事件 ABI 推送已接收条目和总数，界面逐批追加并更新进度；乱序包按目录索引拼成连续前缀再显示，完成时保留已显示行，超时/取消保留部分条目并明确提示未完成 |
| 曲线显示选择 | 按数据到达顺序列出名称与最新值，可搜索、逐项勾选、全选/全不选；只控制显示，不改变设备上报或导出记录 |
| 多波形框与紧凑布局 | 参数/最新值列表位于可调整宽度的左侧；增加/关闭波形框，参数直接拖动到目标框。各框共享时间范围、独立纵轴，参数颜色在移动后保持一致。工具栏统一控件高度，坐标移到底栏；移除原始数据表及页面标题说明，显示范围提供旧版预设和自定义 |
| 波形时间来源 | MCU 单参数上报保存接收时刻的 Unix 秒，坐标与游标显示北京时间（UTC+8）；PLECS 批上报保留上传的 100 微秒计数及回绕扩展，显示仿真秒数。旧版单调时钟记录无法反推实际北京时间 |
| 暂停与实时 | wave、Scope、SFRA 可暂停显示；后台采集与文件写入继续；“回到实时”恢复显示并跟随最新数据 |
| 参数波形持续采集 | 开始后持续接收，手动停止或关闭软件才结束；显示窗口默认最近 30 秒，0 显示全部，窗口不会决定采集停止时间；全图进入暂停历史视图，拖动/缩放按视口读取，回到实时恢复跟随 |
| 参数波形完整历史 | 本次采集原始记录不再按 10 万条淘汰；绘图按时间窗口分桶保留首尾及极值，抽样只影响显示，导出仍使用全部原始记录；停止/正常关闭时自动保存到 exports，可指定输出文件 |
| 串口文本操作 | HEX 或 UTF-8 文本发送，可追加 CRLF，保留文本首尾空格；UTF-8/HEX 接收显示，停止接收、清空显示、导出接收数据 |
| 历史文件 | 打开数据前要求当前页任务结束；打开后脱离先前数据集，避免定时刷新覆盖历史文件 |
| Ethernet 自动发现 | 以太网连接栏“搜索设备”，按启用的 IPv4 接口广播 UDP 5000，重试、按 MAC 去重，使用回复来源 IP 和声明的 TCP 端口；支持取消与重试，不改网卡设置 |
| 连接切换与波特率 | 常见波特率预设 1200～1000000，另有自定义；选取预设即时应用，手工输入在回车/离开输入框后应用。已连接串口通过 SetCommState 修改并回读驱动确认，失败恢复原值。切换传输类型/串口号先取消设备任务并保存，再断开；搜索结果双击设备后自动断开旧连接并连接新设备 |

界面设置单独存放于仓库 `config/native-ui.json`，不覆盖旧配置文件。发送内容、RAM 写入值、输出文件路径不记忆。设置采用临时文件替换方式保存；读取异常在反馈栏提示。自动化测试使用 `build/test-native-ui.json`，不会写用户配置。

串口显示最多保留末尾 64 KiB 字节对应文本；接收数据及淘汰/部分标识仍由后端管理，导出走同一数据接口。二进制内容请用 HEX 查看，UTF-8 显示遇到非法编码会使用替代字符。

## 已有能力

端口号加设备名称、串口/TCP 连接、只读连接端口显示、可折叠侧边栏、旧版六列参数表、浮点显示、模糊搜索、暂存修改、上下限校验、只读/CMD、批量参数操作、九项业务 CLI/Shell、数据导出、Scope/SFRA 图表、J-Link 符号树已具备实现。

## 尚未等同旧版的部分

参数波形完整历史目前驻留内存，内存占用随采集时长增长，不承诺无限容量。自动保存发生在停止或正常关闭时；异常退出恢复及旧版边采边落盘机制尚未移植。每次重新开始创建新数据集，前一次停止时的自动保存文件仍保留。CLI 原有定时采集保持兼容，`wave capture --duration 0` 为持续采集，通过停止/Ctrl+C 结束。

- 持久参考线与参考值表；多波形框及拖动分配已迁移。
- 串口快捷发送预设、多条发送列表和独立收发统计复位。
- Scope/SFRA 的后续协议细节对齐仍需逐项验证。Perf/Trace/链表顺序/J-Link 专用页面已迁移，详见 [四页功能对照](DIAGNOSTIC_PAGE_PARITY.md)。

不将上述项目写成已完成；CAN、升级、Factory Mode、Black Box 仍按当前业务范围排除。

## 验证

`tests/ui/Frame.UiTests.csproj` 包含设置恢复、UTF-8 保存、参数名称双击加入/移出与拒绝时保留原状态、曲线隐藏不丢记录、暂停时后端继续采集及恢复刷新、中文跨分块接收、发送空格/CRLF、清空显示保留数据、切页采集、关闭停止与文件冲刷验证。串口发送以独立 TX 黄金字节验证；不以界面外观代替协议结果。

本轮未修改设备协议或固件；之前的长时实机测试不能作为新增界面功能的完整实机验收。
