# FRAME 2.0.0

本次按照原有版本规则发布 DR 目标用户版本：`a` 为目标用户，`b` 为大功能，`c` 为小功能及后端优化。版本统一为 2.0.0。

## 主要变化

- 用 C++20 后端和 C#/.NET 10 重写 FRAME，交付 CLI、持续交互 Shell、WPF 界面；应用和安装包不再依赖 Python。
- 提供串口调试、参数读写、参数波形、Scope、SFRA、Perf、Trace、链表顺序、J-Link 九项功能；支持串口及 TCP 连接、以太网设备搜索。
- 参数目录渐进显示，保留设备顺序、浮点类型及写入范围检查；双击加入参数波形。
- 参数波形支持多窗口、拖放分配、同步时间轴、游标数值、历史浏览、自适应 Y 轴及停止后续采保留数据。
- Scope 支持对象缓存、触发时刻和实际采样点提示；SFRA 逐点显示幅相数据，读取设备配置与点数信息。
- Perf 行详情、Trace 采集、链表逐条刷新及按对象缓存；J-Link 支持结构体、数组、指针按地址匹配对象，读取后直接显示目标类型和对象名。
- 新增自包含 Windows x64 安装包脚本、统一 VERSION、程序版本信息和 SHA-256/文件清单；安装版配置与导出保存在用户数据目录。

## 安装

下载 `FRAME-Setup-2.0.0.exe`。Windows 10 2004 或更高版本的 x64 系统；.NET 与所需 C++ 运行库随包提供。J-Link Commander 和探针驱动需单独安装。

保留原 FRAME 安装标识并支持升级；旧配置暂不自动转换。安装和卸载均保留用户配置、日志和导出。提供 `.sha256` 和 `.manifest.json` 供核对附件及负载。

## 验证与边界

- 发布前执行原生协议/运行时、CLI/Shell、TCP 及 WPF 回归，并验证安装包文件哈希、安装后 CLI/Shell、GUI 启动与数据目录。
- E507 九项功能与持续运行已有历史实机记录；本次 J-Link 指针解析另作只读实机验证。历史记录不替代发布二进制的两小时运行验收。
- 旧 Shell 的 `jlink funcs/source`、完整成员表达式自动解析、递归读取深度和共享配置快捷命令尚未迁移；当前支持 `symbols/expand/read/write`。仅有 MAP 地址而缺少类型信息时不能推断结构体布局。
- SFRA 点数目前读取设备值，现有协议未提供可编辑点数配置。
- 本版不包含 CAN、升级、Factory Mode、Black Box；尚未完成所有设备/交互组合的人工验收。
