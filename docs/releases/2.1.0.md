# FRAME 2.1.0

本次发布汇总 2.0.2 之后的功能与修复，提供 Windows x64 自包含安装包。

## 通信与设备诊断

- 连接后可切换目标地址，无需重新建立连接。
- 增加 COMM v1（E9）协议收发、编解码和协商能力，同时保留 E8 协议；界面可选择发送协议。
- 串口监视区区分发送、接收和状态记录，支持通信来源筛选、暂停滚动和恢复跟随；断开连接后保留已有记录。
- 加强编解码边界检查和应答匹配。E9 校验直接应答的序号；E8 事务超时或取消后使会话失效，重试前需要重新连接。

## 验证范围

- 原生协议、运行时与 E9 端到端闭环测试，以及 WPF 串口监视回归覆盖本次变更。
- 历史设备测试曾验证 E9 参数列表和部分压缩数据接收；本次发布未重新执行固件烧录或实机协商与压缩发送验证。
- 安装包附带 SHA-256 校验文件和构建清单。
