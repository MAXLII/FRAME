# FRAME 2.0.1

本次更新改进 PLECS 通信确认、参数波形和独立页面窗口。继续使用 C++20 后端与 C#/.NET 10 前端，Windows x64 自包含安装包无需安装 Python 或 .NET 运行时。

## 修复

- 参数写入优先核对 ACK 中的实际值、类型和上下限，避免额外读取失败导致写入成功后仍显示黄色。ACK 超时后通过新读取的参数目录确认结果；不重复发送写入，命令类型仍要求 ACK。
- 修复波形点击“全图”后进入隐藏暂停状态的问题；“全图”“全部”和切换显示窗口后持续刷新。
- PLECS 新一轮仿真时间回退时自动清除旧仿真波形，正确区分计数器自然回绕；普通 MCU 上报保持原有历史保留行为。

## 波形交互

- 新增“清除波形”，保留连接、采集任务和曲线分配；CLI/Shell 增加 `data clear`，NDJSON 用 `reset` 通知新的数据代次。
- 波形默认不全选；双击参数加入波形或拖入波形框时仍自动显示该曲线。
- 鼠标参考线改为同步的细竖线。新增时间差测量：第一条竖线旁显示时间，第二条旁显示 Δt，支持跨框、反向选点和 s/ms/μs 单位。
- 新增“清除测量”图标；清除标记保留采集数据，数据刷新保留测量标记。

## 独立窗口

- 拖动侧栏文字或图标，可将九个页面分别拉出为独立窗口，并同时显示多个页面。
- 最小化保持独立窗口，点击侧栏对应页面恢复显示；点击独立窗口“×”放回主窗口。
- 独立窗口复用原有连接、页面和采集任务；关闭主窗口统一完成停止、文件保存和窗口释放。

## 验证与安装

- 原生协议/运行时测试、CLI/Shell 回归、WPF 页面与采集测试。
- 侧栏展开与收起状态的实际鼠标拖出、最小化恢复、关闭收回和后台波形刷新。
- PLECS-SIM TCP 实测连续接收 10,914 条记录，无缺样和重复；界面在全图、全部历史及切回 30 秒后持续更新。仿真重启自动清除和缺 ACK 回读由协议回放验证。
- 安装包隔离验证覆盖文件哈希、自包含 CLI、Shell 回放、WPF 启动/关闭及配置目录；不覆盖用户已有配置、日志和导出。

下载 `FRAME-Setup-2.0.1.exe` 安装或升级；同页提供 SHA-256 校验文件和安装内容清单。
